# Telegram Bot на базе Claude Sonnet 4.5

Телеграм-бот с двумя основными функциями:
1. **Автоматический постинг новостей** - раз в день находит и постит интересную новость про AI/e/acc/сингулярность
2. **Ответы на упоминания** - отвечает когда его тегают, может фактчекать и высказывать мнение

## Особенности

- Использует Claude Sonnet 4.5 (claude-sonnet-4-5-20250929)
- Хранит логи чата и информацию об участниках
- Постит новости в случайное время между 16:00-23:50 MSK
- Поддерживает контекст разговора
- Ироничный стиль общения

## Требования

- Python 3.8 или новее
- Telegram Bot Token (от @BotFather)
- Anthropic API ключ

## Установка и запуск

### Шаг 1: Установка Python

**Windows:**
1. Скачай Python с [python.org](https://www.python.org/downloads/)
2. При установке **ОБЯЗАТЕЛЬНО** поставь галочку "Add Python to PATH"
3. Проверь установку: открой cmd и напиши `python --version`

**Linux/Mac:**
```bash
# Обычно уже установлен, проверь:
python3 --version

# Если нет, установи:
# Ubuntu/Debian:
sudo apt install python3 python3-pip python3-venv

# Mac:
brew install python3
```

### Шаг 2: Получение API ключей

#### Telegram Bot Token:
1. Найди @BotFather в Telegram
2. Отправь `/newbot`
3. Следуй инструкциям, придумай имя и username для бота
4. Получишь токен вида: `1234567890:ABCdefGHIjklMNOpqrsTUVwxyz`
5. Сохрани этот токен!

#### Anthropic API Key:
1. Зарегистрируйся на [console.anthropic.com](https://console.anthropic.com/)
2. Перейди в раздел API Keys
3. Создай новый ключ
4. Скопируй ключ (начинается с `sk-ant-api03-`)

### Шаг 3: Настройка бота

1. **Скачай или клонируй репозиторий**

2. **Настрой `.env` файл**
   - Открой файл `.env` в текстовом редакторе
   - Вставь свои ключи:
   ```env
   TELEGRAM_BOT_TOKEN=твой_токен_от_BotFather
   ANTHROPIC_API_KEY=твой_ключ_от_Anthropic
   TARGET_CHAT_ID=
   ```

3. **Получи Chat ID** (для автопостинга новостей):
   - Добавь бота в свой чат
   - Отправь любое сообщение в чат
   - Открой в браузере: `https://api.telegram.org/bot<ТУТ_ТВОЙ_ТОКЕН>/getUpdates`
   - Найди `"chat":{"id":-1001234567890}` - это и есть Chat ID
   - Вставь его в `.env` файл в строку `TARGET_CHAT_ID=-1001234567890`

4. **Настрой системный промпт** (опционально)
   - Открой `memory/system_prompt.txt`
   - Отредактируй стиль и поведение бота под свой чат

### Шаг 4: Запуск

#### Windows:
1. Просто запусти `start.bat` (двойной клик)
2. При первом запуске установятся все зависимости
3. Бот запустится!

#### Linux/Mac:
```bash
# Дай права на выполнение:
chmod +x start.sh

# Запусти:
./start.sh
```

#### Альтернативный способ (вручную):
```bash
# Создай виртуальное окружение
python -m venv venv

# Активируй его
# Windows:
venv\Scripts\activate
# Linux/Mac:
source venv/bin/activate

# Установи зависимости
pip install -r requirements.txt

# Запусти бота
python bot.py
```

## Использование

### Команды бота

- `/start` - приветствие и справка
- `/status` - текущий статус бота (кол-во участников, логов, время до поста)
- `/next_post` - когда следующий запланированный пост

### Взаимодействие

**Автоматические новости:**
- Бот сам запостит новость в указанный чат между 16:00-23:50 MSK
- Время выбирается случайно при каждом запуске
- Постит раз в день

**Ответы на упоминания:**
Бот ответит если:
- Его тегнули через `@имя_бота`
- Ответили на его сообщение (reply)
- Упомянули слова: "бот", "клод", "claude"

**Примеры:**
```
Пользователь: @bot что думаешь про эту новость? [ссылка]
Бот: [фактчекает и комментирует в стиле чата]

Пользователь: клод, найди информацию про GPT-5
Бот: [гуглит и отвечает]
```

## Память и логи

Бот хранит:
- **Последние 100 сообщений** в логах (настраивается в `config.py`)
- **Информацию об участниках** (username, роль, количество сообщений)
- **Дату последнего поста** (чтобы не постить дважды в день)

## Работа в фоне

### Windows:
Чтобы бот работал в фоне и не закрывался при закрытии окна:

1. Создай ярлык `start.bat`
2. ПКМ → Свойства → измени "Окно" на "Свернутое в значок"
3. Или используй Task Scheduler для автозапуска

### Linux:
Используй `screen` или `tmux`:
```bash
# Установи screen
sudo apt install screen

# Запусти в screen
screen -S telegram_bot
./start.sh

# Отключись: Ctrl+A, затем D
# Подключись обратно: screen -r telegram_bot
```

Или создай systemd сервис (для постоянной работы):
```bash
# Создай файл /etc/systemd/system/telegram-bot.service
[Unit]
Description=Telegram Bot
After=network.target

[Service]
Type=simple
User=твой_пользователь
WorkingDirectory=/путь/к/bot_telegram_testing
ExecStart=/путь/к/bot_telegram_testing/venv/bin/python bot.py
Restart=always

[Install]
WantedBy=multi-user.target

# Запусти:
sudo systemctl enable telegram-bot
sudo systemctl start telegram-bot
```

## Troubleshooting

**Бот не запускается:**
- Проверь что Python установлен: `python --version`
- Проверь что все ключи в `.env` правильные
- Посмотри логи в консоли

**Бот не постит новости:**
- Убедись что `TARGET_CHAT_ID` указан в `.env`
- Проверь что бот добавлен в чат и имеет права на отправку сообщений
- Проверь время - бот постит между 16:00-23:50 MSK

**Бот не отвечает на упоминания:**
- Убедись что ты правильно его тегаешь
- Проверь что бот видит сообщения (посмотри логи)
- Проверь что Anthropic API ключ валидный и имеет баланс

**"Connection error":**
- Проверь интернет-соединение
- Проверь что Telegram и Anthropic API доступны
- Возможно нужен VPN (если Telegram заблокирован)

## Кастомизация

### Изменить стиль общения:
Отредактируй `memory/system_prompt.txt`

### Изменить время постинга:
В `.env` измени:
```env
POST_TIME_START=12:00
POST_TIME_END=20:00
```

### Изменить количество хранимых логов:
В `config.py` измени:
```python
MAX_LOG_MESSAGES = 200  # Вместо 100
```
